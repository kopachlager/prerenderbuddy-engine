# Prerender Buddy Engine 0.1.0 alpha

This is the first early release of the standalone, Apache-2.0 Prerender Buddy rendering engine. It is intended for teams that want to evaluate or operate crawler rendering inside infrastructure they own.

## Included

- Playwright Chromium rendering with document-status preservation.
- Bearer-token authentication and exact-domain allowlisting.
- Public-network, redirect, DNS-timeout, browser-request, output-size, render-time, and concurrency boundaries.
- Bounded in-memory caching and duplicate-render coordination.
- Docker Compose setup, health/readiness endpoints, protected metrics, and self-hosting guidance.
- Node 20, 22, and 24 tests plus deterministic real-Chromium release fixtures.

## Early-release limitations

Version 0.1 runs one Chromium process, keeps cache and render coordination inside one process, and provides no external telemetry or service-level guarantee. Operators own TLS, crawler routing, network isolation, secrets, monitoring, scaling, backups, upgrades, security response, and incidents.

Managed DNS, distributed scheduling, automatic scaling, dashboard workflows, billing, monitoring, incident ownership, and product support are part of the managed Prerender Buddy service and are not included here.

Read the [self-hosting guide](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.0/docs/self-hosting.md), [security model](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.0/SECURITY.md), and [release security review](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.0/docs/security-review.md) before production use.
