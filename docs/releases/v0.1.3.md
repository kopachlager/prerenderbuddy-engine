# Prerender Buddy Engine 0.1.3 alpha

This corrective distribution release completes the GHCR-backed Docker installation path prepared in `0.1.2`.

## Correction

The `0.1.2` workflow successfully published its public multi-architecture image, but then attempted to administer user-package visibility with a repository-scoped `GITHUB_TOKEN`. GitHub rejected that unsupported operation, so the workflow correctly stopped before generating checksums, attestations, and the GitHub release.

Version `0.1.3` verifies public access through an anonymous GHCR registry token instead. It preserves the same engine boundary while publishing a complete, independently verifiable release.

## Distribution

- Immutable `ghcr.io/kopachlager/prerenderbuddy-engine:v0.1.3` images for `linux/amd64` and `linux/arm64`.
- Image provenance and SBOM attestations.
- Downloadable `docker-compose.yml` and `prerenderbuddy.env.example` installer assets.
- Checksums, dependency SBOM, source archive attestations, and release notes.

Version 0.1 remains an early evaluation release with an in-memory cache and coordination, one Chromium process, and no service-level guarantee. Do not expose the engine as an unauthenticated public proxy, and retain outbound network restrictions. Review the [self-hosting guide](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.3/docs/self-hosting.md) and [security model](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.3/docs/security-review.md) before production use.
