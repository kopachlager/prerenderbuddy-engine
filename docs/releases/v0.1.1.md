# Prerender Buddy Engine 0.1.1 alpha

This corrective alpha closes browser-network escape paths found during the post-release security review and improves the integrity and usability of the self-hosted release process.

## Security correction

- HTTP(S) interception now applies to the entire browser context before any page is created, including the first request from popup pages.
- Service workers are disabled because their requests are not intercepted by Playwright routing.
- WebSocket connections are closed by policy without connecting to the upstream server.
- Real Chromium fixtures verify that popup, service-worker, and WebSocket attempts cannot reach a private probe server.

No public exploitation is known. Operators evaluating `0.1.0` should upgrade to `0.1.1`; do not expose either version as an unauthenticated public proxy, and retain outbound network restrictions.

## Release improvements

- The package, health endpoint, startup output, container metadata, and release tag share one version.
- The Playwright base image and GitHub Actions are pinned by immutable digest or commit.
- Tagged artifacts include checksums, a dependency SBOM, and GitHub build provenance.
- CI adds static analysis and a high/critical container vulnerability gate.
- Installation, upgrades, API behavior, integration boundaries, support, and contribution expectations are documented explicitly.

Version 0.1 remains an early evaluation release with in-memory cache and coordination, one Chromium process, and no service-level guarantee. Review the [self-hosting guide](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.1/docs/self-hosting.md) and [security model](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.1/docs/security-review.md) before production use.
