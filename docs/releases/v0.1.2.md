# Prerender Buddy Engine 0.1.2 alpha

This distribution release makes the reviewed engine easier to install without changing its rendering or security boundary.

## Published container

- Tagged releases publish an immutable `ghcr.io/kopachlager/prerenderbuddy-engine:v0.1.2` runtime image.
- The image supports `linux/amd64` and `linux/arm64`.
- GitHub Actions generates build provenance and an image SBOM.
- The release workflow makes the container public and verifies both platforms without registry authentication.
- Docker Compose pulls the reviewed image by default; an explicit override remains available for local source builds.

## Release assets

The release includes `docker-compose.yml` and `prerenderbuddy.env.example` alongside the source archive, checksums, dependency SBOM, and attestations. This provides a short install path while keeping configuration explicit.

Version 0.1 remains an early evaluation release with an in-memory cache and coordination, one Chromium process, and no service-level guarantee. Do not expose the engine as an unauthenticated public proxy, and retain outbound network restrictions. Review the [self-hosting guide](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.2/docs/self-hosting.md) and [security model](https://github.com/kopachlager/prerenderbuddy-engine/blob/v0.1.2/docs/security-review.md) before production use.
