# Support

Use GitHub Discussions or issues for reproducible community questions, installation problems, and feature proposals. Search existing reports first and include the engine version, deployment method, relevant non-secret configuration, logs, and a minimal reproduction.

Report suspected vulnerabilities privately through the repository Security tab as described in [SECURITY.md](SECURITY.md). Do not put tokens, customer URLs, private infrastructure details, or exploit material in a public issue.

The open-source engine is community-supported and has no response-time or uptime commitment. The managed [Prerender Buddy](https://prerenderbuddy.com) service provides hosted operations and product support separately.
